# research — бэктесты, walk-forward и поиск эджа

Конвейер проверяет нашу же стратегию (та же `strategy.check_signal`, те же
риск-правила) на исторических данных Bybit и ищет, есть ли вообще эдж при
реальных издержках.

## Запуск

```bash
./venv/bin/python research/data.py 7 --refresh   # скачать/обновить кэш 1m (7 дней, 15 символов)
./venv/bin/python research/run_all.py            # полный цикл: бэктест + walk-forward + edge-scan + report.md
```

## Состав

| файл | что делает |
|---|---|
| `data.py` | загрузка 1m-свечей Bybit v5 с кэшем в `cache/`; агрегация в 5m |
| `backtest.py` | событийный бэктест: пост-онли вход с буфером, SL/TP, безубыток, тайм-стоп, комиссии, дневной стоп-аут |
| `indicators_vec.py` | векторные ATR/RSI/BB/EMA — быстрая предфильтрация баров перед точным `check_signal` |
| `walkforward.py` | подбор параметров на прошлом, проверка на будущем (OOS), без подглядывания |
| `edge_scan.py` | логистическая регрессия (numpy) на признаках входа + бакет-анализ (час, ATR, объём, сторона) |
| `run_all.py` | всё вместе + `results/report.md` |
| `lab.py` | лаборатория перебора: 9 семейств сигналов × 4 режима выхода × 3 профиля фильтров, IS 120д/OOS 60д, per-symbol скан (1608+ вариантов) |
| `scenarios.py` | сценарный анализ: raw-эдж без комиссий у топ-вариантов, выживание при комиссиях full/maker-maker/vip |
| `funding.py` | история funding rate Bybit (public) — контекст издержек удержания |

## Модель исполнения (консервативная)

- вход: postOnly по open следующего бара с буфером 3 бп; вход только если бар
  реально прошёл эту цену (эмуляция отказов пост-онли и спреда);
- SL/TP в одном баре → считаем SL первым;
- SL/тайм-стоп → taker-fee (5.5 бп), TP → maker (2 бп).

Отдельно издержки считаются в отчёте: цена круга ≈ 10.5 бп цены, и именно
отношение «издержки / размер стопа» задаёт требуемый винрейт.

## Главные находки (2026-11, 6 месяцев 1m × 15 символов, 2471+ сделок)

1. Текущий конфиг: винрейт 19.3% при требуемых 28.6% (RR 2.5) ещё до комиссий;
   на 6 месяцах ΣR ≈ −828, все 15 символов в минусе, просадка ~100%.
2. Издержки подтверждены по реальным стаканам: спред 0.02–6.5 бп, impact $5k до 3 бп,
   стоимость круга ≈ 0.3–0.7R из-за крошечных стопов (0.15–0.6% цены).
3. Walk-forward (3 фолда, train 90d → test 30d, без подглядывания): лучший выбор
   устойчиво sl_atr_mult=3.5, rr=3.0 — OOS ΣR=−271 против −409 у базового,
   но всё равно отрицательный; consensus на 6 мес: 0/7 месяцев в плюсе.
4. ML-скан: AUC ≈ 0.50 — признаки при входе НЕ предсказывают исход; стороны одинакого плохи.

Вывод: текущая стратегия не имеет эджа — на реальные деньги не включать.
Искать другой генератор сигналов (старший ТФ, структура, трейлинг) и каждую
идею прогонять `run_all.py`; критерий включения: OOS-плюс и большинство месяцев в плюсе.

## Лаборатория перебора (lab.py + scenarios.py, 2026-11)

Полный перебор: 9 семейств сигналов (BB-тренд 15m/1h, сжатие, MR по RSI и VWAP,
Donchian, импульс, pullback, BTC-led) × 4 режима выхода (RR, широкий, трейлинг,
тайм-стоп) × 3 профиля фильтров на 190 днях 1m × 15 символов. Протокол: IS 120д
(отбор) → OOS 60д (чистая проверка), per-symbol скан 1608 вариантов с n>=25.

- Портфельные варианты: 0 из 108 положительны даже на IS.
- Per-symbol: 0 из 1608 проходит и IS+, и OOS+.
- При ZERO-комиссиях raw-эдж есть у 49 из 326 IS+ вариантов (лидер BTC
  pullback+trail: OOS raw +73R на 1237 сделках) — сырой сигнал слабый, но не нулевой.
- При комиссиях maker+taker (7.5 бп круг) положительных нет вообще; при maker-maker
  4 бп «выживают» только 5 вариантов с маржой +0.01…+0.05R/сделка — на грани шума
  исполнения и не выдерживает поправку на многократный перебор.

Направления, подтверждённые данными: крупные стопы/TF (издержки/стоп падают
с ~0.5R до ~0.05R), maker-maker исполнение, узкоспредные монеты. Пока критерий
(OOS-плюс, большинство месяцев в плюсе) не выполнен — **на реальные деньги не выходить**.

## Глубокий коп (deep.py + deep_sym.py + loblog.py, 2026-11)

Микроструктура 1m (серии закрытий, разогрев тел+объём, wick-absorption,
micro-Donchian) × 3 ТФ (1m/15m/1h) × 5 режимов выхода, 294 портфельных +
167 per-symbol IS+ вариантов, IS 120д → OOS 60д:

- Портфель: 3/294 OOS+ (все 15m), с классическим затуханием IS→OOS
  (squeeze +76R → +4.6R). Выживание при maker-maker — маржа ~0.03R/сделку.
- Per-symbol: 67/167 OOS+ = **40% — ниже монетки**, т.е. статистика НЕ отличает
  победителей от случайных. Величины +10…17R при SE≈12R — 1–1.5σ, шум.
- Пул MR-семейств (mr_rsi5+mr_vwap+pullback) по всем 15 монетам: OOS минус
  везде, кроме 15m/tf_trail (mm +8.1R, full −4.2R) — эдж не универсальный.
- Единственный кандидат с двусторонней стабильностью: **APTUSDT 15m mr_rsi5**
  (IS +15.2R/154 сд., OOS +16.5R/83 сд., 3/3 месяцев OOS, выживает при
  полных комиссиях) — требует живой обкатки на paper.
- `loblog.py` — демон собирает live-стакан и ленты сделок BTC/SOL/BNB/XRP
  (дисбаланс, спред, VWAP-уровни, агрессивная дельта) — датасет для будущих
  микро-бэктестов, которых в публичной истории Bybit нет.
